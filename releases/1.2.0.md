## 新增

- **应用内自动更新**：「设置 › 关于 › 检查更新」对接 GitHub Releases——发现新版本后可直接下载，下载完成后自动替换旧程序并重启，无需手动下载；更新失败时自动保留旧版本。启动 90 秒后后台静默检查，之后每 6 小时一次，可在设置中关闭。

## 改进

- 「关于」页的项目主页与开源许可（MIT License）改为可点击链接。

## 其他

- 开源发布整理：README（中文 / 英文）、MIT 许可证、各版本更新日志、GitHub 仓库（Huiiiii0118/12Island）。

## New

- **In-app updates**: "Settings › About › Check for updates" now reads GitHub Releases — a newer version can be downloaded right in the app, which then replaces its own executable and restarts, keeping the old version if anything fails. Background checks run 90 seconds after startup and then every 6 hours, and can be switched off.

## Improved

- The About page's project home and open-source licence (MIT License) are clickable links.

## Other

- Open-source release housekeeping: README (Chinese / English), the MIT licence, per-version release notes and the GitHub repository (Huiiiii0118/12Island).
